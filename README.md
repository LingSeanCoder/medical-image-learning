# Medical Image Learning Journey

This repository documents my learning journey from deep learning fundamentals to medical image analysis and whole-slide image research.

## Current module

Week 1–2: PyTorch, autograd, CNN training, evaluation, and reproducibility.

## Learning objective

Build an image-classification pipeline from scratch:

Dataset → DataLoader → CNN → loss → backpropagation → optimizer → validation → checkpoint → error analysis.

## Environment

- Development: Windows + VS Code
- Training: Google Colab GPU
- Framework: PyTorch

## Repository structure

- `notebooks/`: learning and exploratory notebooks
- `src/`: reusable Python source code
- `docs/`: notes, glossary, research logs, weekly reports
- `outputs/`: figures, metrics, and local checkpoints
